# AQUARIUM local catalog images

The 4×4 source sheet in this directory was generated for the local demo assortment. `scripts/split-catalog-product-contact-sheet.ps1` crops it into the product images under `public/images/`.

Generated product visuals are illustrative. Filter entries use brand names to diversify checkout simulations; their photos are generic and do not show or claim to be official manufacturer models. Capacities, prices, and inventory are demo values.

Fish photo source, author, source page, and license are recorded per file in `public/images/catalog-image-credits.json`. The catalog links each Commons attribution from the image card. `scripts/cache-commons-catalog-photos.ps1` stores the source photos locally as optimized JPEGs when the source host allows the download.
